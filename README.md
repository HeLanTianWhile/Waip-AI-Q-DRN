quantize-Delivery Relay Network（量化递接网络）
Waip Artificial intelligence.main.Delivery Relay Network.quantize-Delivery Relay Network是一个由科文通开发的量化递接网络。
属于类脑架构，用于模拟人类的神经网络。
定下来的参数量：
- 输入层神经元数量：74,884（390*192 + 4）
- 输出层神经元数量：4（2个鼠标移动 + 1个视野移动 + 1个点击）
- 记忆神经元数量：500
- 正常神经元数量：2000
- 神经元总数量：74,884 + 500 + 2000 + 4 = 77,388
- 屏幕尺寸：390 × 844（固定）
- 视野采样：390 × 192（滑动的黄金视野）
- 运行速率：5.4 tick/s
